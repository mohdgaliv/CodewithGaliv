Data Types

Learn Practice Quiz Challenge Complete

Learn

Objective: Python ke basic data types (int, float, str, bool) aur type() function ko samajhna.

Har value ka ek type hota hai. Python dynamically typed hai — matlab type automatically decide hota hai value ke basis par, tumhe declare nahi karna padta.

Important Concepts

  • int — whole numbers, jaise 5, -3, 100.
  • float — decimal numbers, jaise 3.14, -0.5.
  • str — text, quotes me likha jaata hai, jaise "Hello".
  • bool — True ya False.
  • type() function se kisi bhi value ka type check kar sakte ho.

Syntax

Syntax 
type(value)

Common Mistakes

"5" (string) aur 5 (int) ko same samajhna — dono alag types hain.

Boolean values ko lowercase likhna — true/false Python me invalid hai, capital True/False chahiye.

Practice

Python Code 
print(type(5))
Expected Output
<class 'int'>
Python Code 
print(type(3.14))
Expected Output
<class 'float'>
Python Code 
print(type("Hello"))
Expected Output
<class 'str'>
Python Code 
print(type(True))
Expected Output
<class 'bool'>

Quick Recap

  • 4 basic types: int, float, str, bool.
  • type() se kisi bhi value ka type pata chal sakta hai.
  • Python dynamically typed hai — type auto-detect hota hai.
