Arithmetic Operators

Learn Practice Quiz Challenge Complete

Learn

Objective: Python ke arithmetic operators (+, -, *, /, //, %, **) seekhna.

Arithmetic operators numbers par mathematical operations perform karte hain. Python me kuch operators (// aur %) doosri languages se thode different feel ho sakte hain, isliye inhe carefully samjho.

Important Concepts

  • + addition, - subtraction, * multiplication.
  • / division — result hamesha float hota hai.
  • // floor division — sirf integer part deta hai.
  • % modulus — division ka remainder deta hai.
  • ** exponent/power.

Syntax

Syntax 
a + b, a - b, a * b, a / b, a // b, a % b, a ** b

Common Mistakes

/ aur // me confuse hona — / hamesha float deta hai, // sirf integer part.

Power ke liye ^ use karna — Python me ^ XOR operator hai, power ke liye ** use karo.

Practice

Python Code 
print(7 / 2)
Expected Output
3.5
Python Code 
print(7 // 2)
Expected Output
3
Python Code 
print(7 % 2)
Expected Output
1
Python Code 
print(2 ** 3)
Expected Output
8

Quick Recap

  • / hamesha float return karta hai, // integer part.
  • % remainder deta hai.
  • Power ke liye ** use karo, ^ nahi.

Practice Questions

  1. Do numbers lekar unke +, -, *, / results print karo.
  2. Same numbers ka // aur % nikaal kar compare karo / se.
  3. Kisi number ka cube (power 3) ** operator se nikalo.
