Input

Learn Practice Quiz Challenge Complete

Learn

Objective: input() function se user se data lena seekhna.

input() function program ko pause kar deta hai aur user se keyboard se kuch type karwata hai. Jo bhi user type kare, wo hamesha string ke roop me return hota hai — chahe user ne number hi kyun na type kiya ho.

Important Concepts

  • input("prompt") — prompt message dikhata hai aur user ka input leta hai.
  • Return value hamesha str hoti hai.
  • Input ko variable me store karke aage use kar sakte ho.

Syntax

Syntax 
variable = input("Prompt message: ")

Common Mistakes

Sochna ki input() number return karta hai — ye hamesha string hota hai, math ke liye convert karna padta hai (agla lesson).

Prompt message na dena, jisse user ko pata nahi chalta kya type karna hai.

Practice

Python Code 
name = input("Apka naam kya hai? ")
print("Namaste,", name)
Expected Output
Namaste, Galiv

(agar user ne 'Galiv' type kiya ho)

Python Code 
age = input("Apki age kya hai? ")
print(type(age))
Expected Output
<class 'str'>

Quick Recap

  • input() user se keyboard se data leta hai.
  • Return value hamesha string hoti hai.
  • Prompt message dena good practice hai.

Practice Questions

  2. input() se user ki favorite movie pucho aur ek sentence me print karo.
  3. type() use karke verify karo ki input() ka result str hi hai.
