Python Setup aur Execution

Learn Practice Quiz Challenge Complete

Learn

Objective: Apne computer par Python install karna seekhna, aur ek Python file ko run karna seekhna.

Step 1: Python Install Karo

  • python.org/downloads se latest Python version download karo.
  • Windows par install karte waqt "Add Python to PATH" checkbox zaroor check karo — warna terminal se Python nahi chalega.
  • Install hone ke baad terminal/command prompt me check karo:
Terminal 
python --version
Expected Output
Python 3.12.0 (ya jo bhi version install hua)

Step 2: Ek Code Editor Choose Karo

Beginners ke liye VS Code (free, popular) best hai. Python ke saath IDLE bhi built-in aata hai jo simple aur beginner-friendly hai.

python vs python3: Kuch systems (jaise Mac/Linux) par python command Python 2 ko point karta hai aur python3 Python 3 ko. Is course me hum Python 3 use kar rahe hain, isliye agar python kaam na kare to python3 try karo.

Common Mistake

"Add Python to PATH" checkbox miss karna sabse common Windows installation mistake hai — iske bina terminal "python is not recognized" error dega.

Practice

Ek .py file run karne ka standard tareeka:

Terminal 
python filename.py
Expected Output
filename.py ke andar jo bhi print() statements hain, wo yahan show honge.

Apne computer par ek folder banao, usme test.py file create karo, aur agli lesson me hum usme pehla program likhenge.
