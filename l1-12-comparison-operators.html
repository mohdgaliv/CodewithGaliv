Comparison Operators

Learn Practice Quiz Challenge Complete

Learn

Objective: Comparison operators (==, !=, >, <, >=, <=) seekhna, jo hamesha bool return karte hain.

Comparison operators do values compare karte hain aur result hamesha True ya False hota hai. In operators ka use conditions (if statements) me bahut hoga, jo agle level me seekhenge.

Important Concepts

  • == equal to, != not equal to.
  • > greater than, < less than.
  • >= greater or equal, <= less or equal.
  • Result hamesha bool (True/False) hota hai.

Syntax

Syntax 
a == b, a != b, a > b, a < b, a >= b, a <= b

Common Mistakes

= (assignment) aur == (comparison) me confuse hona.

Different types compare karna unexpected result de sakta hai — jaise "5" == 5 gives False, kyunki types alag hain.

Practice

Python Code 
print(5 == 5)
Expected Output
True
Python Code 
print(5 != 3)
Expected Output
True
Python Code 
print(3 < 5)
Expected Output
True
Python Code 
print(10 >= 15)
Expected Output
False

Quick Recap

  • Comparison operators hamesha bool return karte hain.
  • == comparison hai, = assignment hai — confuse mat karo.
  • Different types compare karne se False mil sakta hai.

Practice Questions

  1. Do numbers compare karo == se aur result print karo.
  2. Ek number ko dusre se > aur < dono se compare karo.
  3. String "5" aur int 5 ko == se compare karke result predict karo, phir verify karo.
