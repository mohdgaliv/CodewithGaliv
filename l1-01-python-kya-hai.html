Python Kya Hai?

Learn Practice Quiz Challenge Complete

Learn

Objective: Is lesson ke baad aap samajh paoge ki Python kya hai, ye kisne banaya, aur real world me ye kahan use hota hai.

Python ek high-level, general-purpose programming language hai. Isko Guido van Rossum ne banaya tha aur pehli baar 1991 me release kiya gaya.

"High-level" ka matlab hai ki Python ki language English jaisi simple aur readable hai — aapko computer ke internal hardware details (memory addresses, registers) ke baare me sochne ki zaroorat nahi hai. "General-purpose" ka matlab hai ki Python sirf ek specific kaam ke liye nahi, balki web development, data science, automation, AI/ML, scripting — har jagah use ho sakta hai.

Important Concepts

  • High-level language: Human-readable syntax, machine details se abstracted.
  • Interpreted language: Code line-by-line run hota hai (detail Lesson 2 me).
  • Dynamically typed: Variable ka type declare karne ki zaroorat nahi (detail Lesson 8 me).
  • Open-source: Python free hai aur koi bhi ise use/modify kar sakta hai.

Common Mistake

Naye learners sochte hain ki Python sirf beginners ke liye hai ya "toy language" hai. Reality me Python industry me heavily use hota hai — Instagram, YouTube, Google, NASA, aur bade AI systems bhi Python use karte hain.

Python Kahan Use Hota Hai?

  • Web Development (Django, Flask)
  • Data Science & Machine Learning (Pandas, NumPy, TensorFlow)
  • Automation & Scripting
  • Game Development
  • Cybersecurity & Ethical Hacking

Practice

Neeche Python ki simplicity ka ek example dekho — sirf ek line me output print ho jaata hai:

Python Code 
print("Python seekhna shuru!")
Expected Output
Python seekhna shuru!

Compare karo — same output C ya Java me likhne ke liye extra setup (main function, semicolons, curly braces) chahiye hota. Python me sirf ek line kaafi hai. Yehi Python ki readability aur simplicity hai.
