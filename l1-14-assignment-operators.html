Assignment Operators

Learn Practice Quiz Challenge Complete

Learn

Objective: Compound assignment operators (+=, -=, *=, /=, etc.) seekhna.

Compound assignment operators ek shorthand hain — jaise x += 1 ka matlab hai x = x + 1. Ye code ko chhota aur readable banate hain.

Important Concepts

  • = basic assignment.
  • +=, -=, *=, /= — add/subtract/multiply/divide aur assign.
  • //=, %=, **= — floor divide, modulus, aur power ke liye bhi shorthand.

Syntax

Syntax 
x += 1  # same as x = x + 1

Common Mistakes

+= ko == samajh lena — ye assignment hai, comparison nahi.

Variable ko compound assign karne se pehle define na karna — x += 1 tab error dega agar x pehle se exist nahi karta.

Practice

Python Code 
x = 5
x += 3
print(x)
Expected Output
8
Python Code 
x = 10
x -= 4
print(x)
Expected Output
6
Python Code 
x = 2
x *= 5
print(x)
Expected Output
10

Quick Recap

  • += ka matlab x = x + value.
  • Compound operators code ko shorter banate hain.
  • Variable pehle se defined hona chahiye.

Practice Questions

  1. x = 10 se start karke += se 5 add karo.
  2. Same x ko -= se 3 subtract karo.
  3. x ko *= se double karo aur final value print karo.
