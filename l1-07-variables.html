Variables

Learn Practice Quiz Challenge Complete

Learn

Objective: Variables kya hote hain, naming rules kya hain, aur values kaise store/reassign karte hain.

Variable ek naam hai jo memory me kisi value ko point karta hai. Python me variable declare karne ke liye koi keyword (jaise int ya var) nahi chahiye — bas = se assign karo.

Important Concepts

  • = assignment operator hai — x = 5 ka matlab hai x ko 5 assign karo.
  • Dynamic typing: Type declare karne ki zaroorat nahi, Python khud detect karta hai.
  • Naming rules: Letters, digits, underscore allowed; digit se start nahi ho sakta; case-sensitive hai.
  • Multiple assignment: a, b, c = 1, 2, 3 ek saath 3 variables set kar sakta hai.

Syntax

Syntax 
variable_name = value

Common Mistakes

Variable naam digit se start karna, jaise 1name = "x" — SyntaxError aata hai.

Reserved keywords (jaise class, if) ko variable naam banana.

Case-sensitivity bhool jaana — Name aur name do alag variables hain.

Practice

Python Code 
name = "Galiv"
age = 20
print(name, age)
Expected Output
Galiv 20
Python Code 
x = 5
x = x + 1
print(x)
Expected Output
6
Python Code 
a, b, c = 1, 2, 3
print(a, b, c)
Expected Output
1 2 3

Quick Recap

  • Variable = ke through banate hain, koi type keyword nahi chahiye.
  • Naam digit se start nahi ho sakta aur reserved keyword nahi ho sakta.
  • Multiple assignment se ek line me kai variables set kar sakte ho.

Practice Questions

  1. 3 variables banao: naam, age, city — aur unhe print karo.
  2. Ek variable ki value ko reassign karo aur naya print karke check karo.
  3. Multiple assignment use karke 2 variables ek line me banao.
