Type Conversion

Learn Practice Quiz Challenge Complete

Learn

Objective: Explicit type conversion (casting) seekhna — int(), float(), str() functions.

Kabhi kabhi ek type ki value ko dusre type me convert karna padta hai — jaise input() se aayi string ko number me convert karna, math karne ke liye. Isse type conversion ya casting kehte hain.

Important Concepts

  • int(value) — value ko integer me convert karta hai.
  • float(value) — value ko decimal number me convert karta hai.
  • str(value) — value ko string me convert karta hai.
  • Kuch cases me Python implicit conversion khud kar leta hai (jaise int + float = float).

Syntax

Syntax 
int(value), float(value), str(value)

Common Mistakes

int("hello") likhna — ValueError aata hai, kyunki "hello" number nahi hai.

Input se aayi string ko convert kiye bina directly + karna — numbers add hone ki jagah strings concatenate ho jaati hain ("5"+"10" = "510", 15 nahi).

Practice

Python Code 
age = input("Age: ")
age = int(age)
print(age + 1)
Expected Output
21

(agar user ne '20' diya ho)

Python Code 
print(str(100) + " rupees")
Expected Output
100 rupees
Python Code 
print(int("5") + int("10"))
Expected Output
15

Quick Recap

  • int(), float(), str() se explicit conversion karte hain.
  • Non-numeric string ko int() karne par ValueError aata hai.
  • input() ka result math ke liye pehle convert karna zaroori hai.

Practice Questions

  1. input() se ek number lo (string ke roop me) aur usko int() se convert karo.
  2. Convert kiye hue number me 10 add karke print karo.
  3. str() use karke ek number ko text ke saath combine karo (jaise 'Total: 50').
