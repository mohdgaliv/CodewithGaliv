Operator Precedence

Learn Practice Quiz Challenge Complete

Learn

Objective: Operators ka evaluation order (precedence) samajhna, taaki expressions sahi se predict kar sako.

Jab ek expression me multiple operators hote hain, Python ek fixed order follow karta hai ki kis operator ko pehle evaluate karna hai. Roughly ye order hai: () sabse pehle, phir **, phir * / // %, phir + -, phir comparisons, phir logical operators.

Important Concepts

  • Parentheses () sabse high priority.
  • Exponent ** next.
  • Multiplication/Division/Floor-division/Modulus next.
  • Addition/Subtraction next.
  • Comparisons, phir logical operators (not, and, or) sabse last.
  • Confusion ho to parentheses use karo clarity ke liye.

Syntax

Syntax 
(expression)  # parentheses se order force kar sakte ho

Common Mistakes

Assume karna ki Python hamesha strictly left-to-right evaluate karta hai — precedence rules is order ko override karte hain.

Complex expressions me parentheses use na karna, jisse bugs aate hain aur code padhna mushkil ho jaata hai.

Practice

Python Code 
print(2 + 3 * 4)
Expected Output
14

(20 nahi, kyunki * pehle evaluate hota hai)

Python Code 
print((2 + 3) * 4)
Expected Output
20
Python Code 
print(10 - 2 ** 2)
Expected Output
6

(2**2=4 pehle, phir 10-4=6)

Quick Recap

  • () sabse pehle evaluate hota hai.
  • ** > */ // % > + - > comparisons > logical operators.
  • Clarity ke liye parentheses use karna best practice hai.

Practice Questions

  2. `(5 + 2) * 3` ka result predict karo, phir verify karo.
  3. `20 - 3 ** 2` ka result predict karo, phir verify karo.
