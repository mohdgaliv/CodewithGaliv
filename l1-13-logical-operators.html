Logical Operators

Learn Practice Quiz Challenge Complete

Learn

Objective: and, or, not operators seekhna aur multiple conditions combine karna.

Logical operators multiple boolean conditions ko combine karte hain. Python me ye words ki tarah likhe jaate hain (and, or, not), symbols ki tarah nahi.

Important Concepts

  • and — dono conditions True hone chahiye, tabhi True milega.
  • or — koi ek condition True ho to True milega.
  • not — value ko invert (True↔False) karta hai.

Syntax

Syntax 
condition1 and condition2, condition1 or condition2, not condition

Common Mistakes

&& ya || use karna — ye Python me invalid hai, and/or use karo.

Operator precedence bhool jaana — not pehle evaluate hota hai, phir and, phir or.

Practice

Python Code 
print(True and False)
Expected Output
False
Python Code 
print(True or False)
Expected Output
True
Python Code 
print(not True)
Expected Output
False
Python Code 
age = 20
print(age > 18 and age < 60)
Expected Output
True

Quick Recap

  • and, or, not — words ki tarah likhe jaate hain.
  • and: dono True chahiye. or: ek True kaafi hai.
  • not value ko invert karta hai.

Practice Questions

  1. Do conditions banao aur unhe and se combine karo.
  2. Same conditions ko or se combine karke compare karo.
  3. Kisi condition ko not se invert karo.
