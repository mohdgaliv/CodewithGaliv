Python Kaise Kaam Karta Hai?

Learn Practice Quiz Challenge Complete

Learn

Objective: Samajhna ki jab hum Python code run karte hain, uske peeche kya hota hai — interpreter aur Python Virtual Machine (PVM) ka role.

Kuch languages (jaise C) compiled hoti hain — pura code ek baar me machine code me convert hota hai, phir run hota hai. Python interpreted hai — code line-by-line padha aur execute kiya jaata hai.

Python Execution Process

  1. Aap .py file me source code likhte ho.
  2. Python interpreter is code ko bytecode (.pyc) me convert karta hai — ye ek intermediate, platform-independent format hai.
  3. Bytecode Python Virtual Machine (PVM) par run hota hai, jo actual instructions execute karta hai.
Interpreted vs Compiled: Interpreted languages line-by-line run hoti hain (easier debugging, thoda slower), jabki compiled languages pehle pura translate hoti hain (fast execution, lekin extra compile step).

Common Mistake

Log sochte hain ki Python "sirf interpreted" hai aur bytecode step exist hi nahi karta. Reality me Python pehle bytecode banata hai, phir PVM us bytecode ko interpret karta hai — dono steps hote hain.

Practice

Jab tum terminal me ye command chalate ho:

Terminal 
python hello.py
Kya Hota Hai (Output)
hello.py ka code line-by-line PVM ke through execute hota hai, aur jo bhi print() likha hai wo terminal me show hota hai.

Agar file me error hai (jaise typo), to interpreter us line tak pahunch kar rukk jaata hai aur error message dikhata hai — poora program pehle se "compile-check" nahi hota jaisa kuch languages me hota hai.
