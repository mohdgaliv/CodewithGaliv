Comments

Learn Practice Quiz Challenge Complete

Learn

Objective: Comments kya hain aur code ko readable/maintainable banane ke liye kaise use karte hain.

Comments interpreter ignore karta hai — ye sirf humans ke padhne ke liye hote hain, code ko explain karne ke liye. Single-line comment # se shuru hota hai, multi-line comment triple quotes se likha ja sakta hai.

Important Concepts

  • # comment — single-line comment.
  • ''' ... ''' ya """ ... """ — multi-line comment (technically ek unassigned string, jo Python ignore kar deta hai).
  • Good comments explain why, na ki obvious what.

Syntax

Syntax 
# this is a single-line comment

Common Mistakes

Bahut obvious cheezon pe comment likhna, jaise x = 5 # x ko 5 assign kiya — ye useless hai.

Code change hone par comments ko update na karna, jisse wo outdated/misleading ho jaate hain.

Practice

Python Code 
# Ye program greeting print karta hai
print("Namaste!")  # inline comment
Expected Output
Namaste!
Python Code 
"""
Ye multi-line comment hai
jisme kai lines ho sakti hain
"""
print("Comments seekh liya!")
Expected Output
Comments seekh liya!

Quick Recap

  • # se single-line comment likhte hain.
  • Comments execute nahi hote, sirf documentation ke liye hote hain.
  • Achhe comments "why" explain karte hain, "what" nahi.

Practice Questions

  1. Apne kisi purane print() program me har line ke upar ek comment likho.
  2. Ek multi-line comment likho jo tumhare program ka purpose explain kare.
  3. Ek inline comment (code ke saath same line par) likh kar practice karo.
