First Python Program

Learn Practice Quiz Challenge Complete

Learn

Objective: Apna pehla real Python program likhna aur samajhna ki .py file kaise banti aur run hoti hai.

Koi bhi text editor (VS Code, Notepad, IDLE) me ek naya file banao aur usse .py extension ke saath save karo, jaise hello.py. Usme Python code likho, save karo, phir terminal me python hello.py (ya python3 hello.py) run karo.

Important Concepts

  • .py file: Har Python program isi extension me save hota hai.
  • Filename rules: Lowercase, underscores use karo, spaces avoid karo (jaise hello_world.py).
  • Running: Terminal se, ya IDE ke Run button se.

Syntax

Syntax 
print("Hello, World!")

Common Mistakes

File ko .txt me save kar dena instead of .py.

Filename me space use karna (jaise my program.py) — terminal me path quote karna padta hai.

Wrong folder/directory se run karne ki koshish karna.

Practice

Python Code 
print("Mera pehla Python program!")
print("Naam:", "Galiv")
Expected Output
Mera pehla Python program! Naam: Galiv

Quick Recap

  • Python files .py extension me save hoti hain.
  • Terminal se python filename.py se run hoti hain.
  • IDE me Run button se bhi execute kar sakte ho.

Practice Questions

  1. Ek naya file practice.py banao aur usme apna naam print karo.
  2. Us file me 2 aur print statements add karo.
  3. File ko terminal se run karke output verify karo.
