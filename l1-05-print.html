print()

Learn Practice Quiz Challenge Complete

Learn

Objective: print() function ko deeply samajhna — multiple values, sep, aur end parameters ka use.

print() Python ka built-in function hai jo output screen (console) par dikhata hai. Multiple values ko comma se separate karke ek hi print() me pass kar sakte ho.

Important Concepts

  • print(value) — ek value print karta hai.
  • print(a, b, c) — multiple values, comma se separated.
  • sep parameter — values ke beech kya aayega (default: space).
  • end parameter — print ke baad kya aayega (default: newline \n).

Syntax

Syntax 
print(value1, value2, sep=' ', end='\n')

Common Mistakes

Python 2 style print "text" likhna (bina parentheses ke) — Python 3 me ye SyntaxError deta hai.

String values ke around quotes lagana bhool jaana.

Practice

Python Code 
print("Hello", "World")
Expected Output
Hello World
Python Code 
print("A", "B", "C", sep="-")
Expected Output
A-B-C
Python Code 
print("No newline", end=" ")
print("next part")
Expected Output
No newline next part

Quick Recap

  • print() screen par output dikhata hai.
  • Default separator space hai, default end newline hai.
  • sep aur end parameters se behavior customize kar sakte ho.

Practice Questions

  2. Same 3 values ko sep='|' ke saath print karo.
  3. end=' ' use karke 2 print() statements ko same line pe print karo.
